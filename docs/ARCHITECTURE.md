# Ancient Roman Temporal Clock

Roman seasonal clocks and their unequal-daylight tick policy are provider-specific. Common 1.19.81 at a99ef676b0e43c7e645c81756e3fd38be0a54406 owns all generic arithmetic, civil coordinates and native resource ABI. The module links the actual reviewed Common static library via an exact submodule; stronger local solar modelling is retained pending public Common parity, while source installers and model fixtures are preserved.
