# Ancient Roman Temporal Clock

Roman seasonal clocks and their unequal-daylight tick policy are provider-specific. Common 1.19.80 at dc4aac326964ca4400b6e21851d16eea674040c8 owns all generic arithmetic, civil coordinates and native resource ABI. The module links the actual reviewed Common static library via an exact submodule; stronger local solar modelling is retained pending public Common parity, while source installers and model fixtures are preserved.
